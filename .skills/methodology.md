# Методика и границы обзора

- Объект аудита: содержимое `/home/frys/projects` на сервере `100.64.0.2`, просмотренное 2026-10-01.
- Найдено шесть непосредственных каталогов. Все шесть прочитаны после того, как доступ к ним был открыт.
- `Arcania-workspace` (ветка `dev`) и `Frontend-workspace` (ветка `main`) имеют одинаковый Git origin. Карточки разделены, так как checkout и структура отличаются; в таблице стека присутствуют два счётчика: физические каталоги `/6` и уникальные root origins `/5`.
- `Elux` включает root repo с Git submodules `core` и `web`, плюс Rust crate `xray`. Submodule коды прочитаны отдельно. `VortexDL` также включает локальные Git submodules с SoundCloud и YouTube downloader crates. Из manifests выгружено 386 прямых dependency entries; версии в CSV — заявленные диапазоны или локальный path, не разрешённые lockfile-версии.
- Частота означает наличие прямого объявления в manifest/build file либо подтверждение в исходном коде. Она не обозначает число файлов, строк, часов или владение технологией на экспертном уровне.
- Год и даты взяты из наблюдаемой Git истории; версия VortexDL — из manifest и release commit. Это не обязательно дата начала разработки или полный публичный релизный цикл.
- Авторство оценивается осторожно по Git author metadata. Ветки/submodules/коммиты могут использовать alias; git statistics не доказывает личное авторство каждой строки.
- В анализе не раскрывалось содержимое `.env`/секретных переменных. Учитывались только названия конфигурационных файлов и их использование.
- Сборки, тесты, deploy workflow и runtime сценарии не запускались. Файлы тестов/команд подтверждают наличие конфигурации или кода тестов, а не успешный результат прогона.
- `git status` обнаружил изменения в Elux, VortexDL и Zonex. Отчёт описывает видимое состояние, в том числе незакоммиченный код, без изменения содержимого проектов.
